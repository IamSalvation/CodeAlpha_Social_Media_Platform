# Decoded_Social_Media_Platform

A dynamic, interactive three-column social media dashboard feed built with Node.js, Express, and CSS Grid. This application features real-time frontend state management allowing users to create posts, write nested comments, toggle likes, and interact with user profiles.

## 🚀 Features

* **Three-Column Grid Architecture:** Organized layout splitting user profiles, main timelines, and dynamic discovery sidebars.
* **Dynamic Post Engine:** Instantly publish new text posts to the feed without reloading the page.
* **Interactive Engagement:** Functional real-time like buttons and custom nested comment threads.
* **Express Backend Server:** Built-in local server delivery configuration running smoothly on Port 5000.

## 🛠️ Tech Stack

* **Frontend UI:** HTML5, CSS Grid & Flexbox, JavaScript (ES6 DOM Manipulation)
* **Backend Server:** Node.js, Express.js
* **Version Control:** GitHub
